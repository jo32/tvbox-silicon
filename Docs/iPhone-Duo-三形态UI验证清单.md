## 形态判定速查

| 形态 | size class | 触达方式 |
|---|---|---|
| 外屏（合拢·竖） | compact × compact | 合拢即默认 |
| 内屏横屏（展开·横持） | phone + regular × regular | 展开 + 横持 |
| 内屏竖屏（展开·竖持） | phone + regular × regular | 展开 + 竖持 |

> 注意：内屏横屏与内屏竖屏的 size class 相同（regular×regular），区别只在持握方向，
> 播放器会据 `landscapeLayout`/`fillsLandscape` 判定横屏控制栏。两态都要验。

## 四、本次修复的回归验证点（三种形态下任选其一点验）

| 修复项 | 验证点 |
|---|---|
| importConfig 双向失效 | 设置 → 订阅 → 导出配置 → 删一个订阅 → 导入该配置 → 订阅应恢复、计数正确 |
| relay 地址丢端口/query | 给一个带端口的源切 Proxy → 再切回 Direct，地址不损坏、能播 |
| 源探测取消误记 | 选集器里快速切换线路，被中断的线路不应变红「不可达」 |
| 线路退避冷却 | 一条线路失败后，应出现冷却倒计时、不立即重试 |
| 隐私保险箱改密码 | 设置密码 → 改密码 → 用新密码应能解锁 |
| 黑背景铺满详情列 | 展开态选集页右侧简介背景正常（非纯黑） |
| macOS 选集死按钮 | （需 macOS 客户端）播放器「选集」按钮应弹出选集列表 |
| URL 冷启动导入 | 杀 App → `yingxia://subscribe?url=...` 冷启动 → 订阅应导入（不丢） |
