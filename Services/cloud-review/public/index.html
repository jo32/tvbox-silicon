Yingxia Cloud Files Review Demo

A read-only, AList v3-compatible demonstration server for Yingxia TestFlight review. It is a small protocol fixture, not an AList/OpenList installation. It contains only generated test media and text, with no personal cloud drive or subscription.

  1. In Yingxia, open Cloud Files → Add Server.
  2. Enter https://yingxia-review.getmegaportal.com. Leave username, password and starting folder at their defaults. Save and open the server.
  3. Open Samples. Try Nested, Empty, Large Folder (125 files), Mixed Files, Sample Video.mp4 and Sample Audio.m4a.
  4. For the Protected folder, enter yingxia-demo. This public demo password exercises the folder-password prompt; the sample files are public.
  5. Play Sample Video.mp4, seek, return to browsing, then check Continue Watching. The video lasts 30 seconds; the audio lasts 15 seconds.

All audiovisual samples were generated specifically for this demonstration. There are no uploads, editable storage, personal accounts or third-party media. The demo does not test real cloud-provider sign-in, write operations or every AList/OpenList storage driver.
